          CREATOR.FEED

          CREATORS WORTH WATCHING

          Add creators from any platform. Enable entries to publish them. Lower display-order numbers appear first; ties follow entry order.

          For YouTube uploads and automatic channel photos, paste a channel URL or @handle into CHANNEL / PROFILE URL and click LOOK UP YOUTUBE CHANNEL, then save. You can also enter the UC... channel ID manually (24 characters). On YouTube, open the channel description / About, then Share channel > Copy channel ID; for your own channel, use Settings > Advanced settings. Leave the ID blank for profile links only. Public feeds can include Shorts and livestreams; uploads and photos are cached for up to ten minutes. If YouTube blocks a photo request, initials are shown instead.

          For Twitch, paste a channel URL or username and click LOOK UP TWITCH CHANNEL, then save. Twitch channel URLs automatically enable profile photos, live status with a Watch live link, and the latest available past broadcast when offline. No separate channel ID is needed. The server needs TWITCH_CLIENT_ID and TWITCH_CLIENT_SECRET configured in Supabase. Status is cached for up to one minute; reopen the feed or use Refresh to update it. VODs may be expired, unavailable, or subscriber-only. Other platforms show initials.

          HARDWARE.SYS

          REAL MACHINE SPECS
          IMPORT_FROM_PC
          1. Pick the platform and copy the scan script. On Windows, paste it into PowerShell. On Linux or Unraid, paste it into a terminal (Unraid: the >_ terminal icon, or SSH as root).
          2. It reads CPU, GPU, RAM, motherboard, storage, and OS (plus displays on Windows and network cards on Linux). Windows copies the result to your clipboard; Linux prints one JSON line to copy. Nothing is uploaded.
          3. Paste the result and import. Windows scans name the machine from its model, or from the device name when the model is generic (custom builds); change the name first if you like. Review the rows, then save.

          LIVE_AGENTS
          1. Create a device token. Leave the name blank and the agent names the machine from its model (or device name) on its first sync, or type a name to set it yourself. The token is shown once; only its hash is stored.
          2. Copy the installer, paste it into PowerShell on that machine (no admin rights needed), and paste the token when prompted.
          3. The agent runs at logon, posts live CPU, GPU, RAM, and uptime every 3 seconds while someone is viewing HARDWARE.SYS (every 15 seconds otherwise), and re-syncs specs every six hours. Re-run the installer to upgrade it; press Enter at the prompt to keep the saved token. Its rows are marked // AGENT. Untick a row to hide it; deleted rows come back on the next sync. Use RENAME here or in the editor to rename a machine; the agent keeps syncing under the new name.

          Unraid NAS: create a separate device token with an explicit public-safe name (for example NAS). Do not use the Windows installer. Follow the Unraid Docker collector setup. Add only reviewed hardware model descriptions in the inventory below; the collector never imports hostnames or serial numbers.

            Publishes to HARDWARE.SYS on /online/. Each machine has its own component list. Add, edit, or remove parts, untick Shown to hide one, then save. Use Move up and Move down to set the public device order, including live devices without components, then save.

            BLOG.LOG

            MARKDOWN PUBLISHING CONSOLE

            Publishing saves to the live database; it does not trigger a site rebuild. New posts remain readable through the live blog archive and legacy post links. Run a deployment to generate or refresh static articles, search-engine metadata, the RSS feed, and sitemap. Scheduled posts enter those files only on a deployment after their publish time. Unpublishing or deleting a post hides it from live queries immediately, but its existing static page and feed entry remain public until the next deployment removes them.
