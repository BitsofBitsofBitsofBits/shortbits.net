IMPORT_FROM_PC
  1. Copy the scan script, open PowerShell on the machine, paste it, and press Enter.
  2. It reads CPU, GPU, RAM, motherboard, storage, displays, and OS, then copies the result to your clipboard. Nothing is uploaded.
  3. Name the machine below, paste the result, and import. Review the rows, then save.
LIVE_AGENTS
  1. Enter the machine name and create a device token. The token is shown once; only its hash is stored.
  2. Copy the installer, paste it into PowerShell on that machine (no admin rights needed), and paste the token when prompted.
  3. The agent runs at logon, posts live CPU, GPU, RAM, and uptime every 3 seconds while someone is viewing HARDWARE.SYS (every 15 seconds otherwise), and re-syncs specs every six hours. Re-run the installer to upgrade it; press Enter at the prompt to keep the saved token. Its rows are marked // AGENT. Untick a row to hide it; deleted rows come back on the next sync.

    Publishes to HARDWARE.SYS on /online/. Rows with the same machine name are grouped together, in the order shown here.
