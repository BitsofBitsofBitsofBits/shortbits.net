# shortbits.net

The source for [shortbits.net](https://www.shortbits.net/), the terminal-inspired
personal website of BitsofBitsofBits. Part profile, part interactive desktop,
and a personal learning project.

## Explore

- **[Online](https://www.shortbits.net/online/):** social and project links,
  desktop-style windows, music, games, and Easter eggs.
- **[Professional](https://www.shortbits.net/professional/):** career highlights,
  projects, a printable resume, and a contact form.
- **[Blog](https://www.shortbits.net/blog/):** project updates and longer-form notes.

The site includes customizable themes, accessibility preferences, and an Admin
center for managing content. It is built with HTML, CSS, and JavaScript, with
Supabase powering content and integrations.
